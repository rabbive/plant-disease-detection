    How it works and the safety rules

    Photo → 224×224 → MobileNetV2 (pre-trained on ImageNet, last 30 layers fine-tuned on 12,707 PlantVillage tomato leaves) → global average pooling → 10-class softmax. The heatmap is a class activation map: the last convolutional feature maps weighted by the output layer's weights for the class shown.

    Three rules sit on top of the raw output. The thresholds were picked on the validation split and checked once on the 2,734-image test split:

    RuleWhyEffect on test set
    Say "Healthy" only at ≥ 90%; otherwise show the most likely disease A sick leaf called healthy is the costliest mistake Sick leaves called healthy: 56 → 7. Accuracy 91.4% → 92.8%
    Flag answers under 60% as "not sure" The model is right only about half the time there 6.8% flagged; 95.2% accuracy on the rest
    Reject photos that don't look like a tomato leaf The model alone was ≥ 60% "sure" on 27 of 33 non-leaf images Accepts 99.5% of test leaves; rejected 33/33 non-leaf images
    91.33% accuracy on 2,734 held-out test images (a CNN trained from scratch gets 85.37%). Works best on one leaf against a plain background, like the training photos; field photos score lower. The advice is general guidance, not a diagnosis. Source code and full results.
